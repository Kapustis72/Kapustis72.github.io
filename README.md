# Политики конфиденциальности (GitHub Pages)

Репозиторий для сайта `https://kapustis72.github.io/`.

После включения Pages (Settings → Pages → Deploy from a branch → `main` / `/ (root)`):

- Про-Путь: https://kapustis72.github.io/proput.html
- Грелка: https://kapustis72.github.io/grelka.html

## Как обновлять

1. Править канон в приложении:
   - Про-Путь: `C:\putlist\store\rustore\legal\privacy-policy.html`
   - Грелка: `C:\grelka\store\rustore\legal\privacy-policy.html`
2. Скопировать HTML сюда (`proput.html` / `grelka.html`).
3. Закоммитить и запушить этот репозиторий.
4. Проверить URL в режиме инкогнито.

Не класть эти файлы в `CO3` / `CO_Timeweb`.
